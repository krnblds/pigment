# Getting help

- **New to Pigment?** Start with [Getting started](docs/GETTING_STARTED.md).
- **How does it work inside?** See [docs/DESIGN.md](docs/DESIGN.md) and the per-feature notes in [`docs/agents/`](docs/agents).
- **Found a bug?** [Open a bug report](https://github.com/krnblds/pigment/issues/new?template=bug_report.md).
- **Have an idea?** [Suggest a feature](https://github.com/krnblds/pigment/issues/new?template=feature_request.md).
- **Security problem?** Follow [SECURITY.md](SECURITY.md). Don't post it publicly.
